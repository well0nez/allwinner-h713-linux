# packages.txt - package list for the slim HY310 rootfs (Debian trixie/arm64)
#
# Basis: doku/107-plan-rootfs.md section 6 (draft) and section 8 (decided).
# The base is `mmdebstrap --variant=minbase`; this file lists only what comes ON TOP.
#
# Format: one line per package. Everything from '#' on is a comment, blank lines allowed.
# build-rootfs.sh reads the file and turns it into the --include list.
#
# Rule for this list: every line has to trace back to a need that is written
# down in the project - no package "just in case".

# --- Init, devices, bus ------------------------------------------------------
systemd-sysv        # /sbin/init; minbase brings systemd as a library, not as init
udev                # device detection; carries 99-h713-tv.rules, without udev h713-tv never starts
dbus                # expected by systemd (logind, hostnamed) and udev rules with TAG+="systemd"

# --- Network (as today in the netboot root, S41 section 1) -------------------
ifupdown            # /etc/network/interfaces: allow-hotplug eth0 / iface eth0 inet dhcp
isc-dhcp-client     # the DHCP client that ifupdown calls; writes /etc/resolv.conf
iproute2            # ip(8); ifupdown and any network troubleshooting need it

# --- Network diagnostics (O2) ------------------------------------------------
# The image had none of these, so "is the network up" could only be answered
# from the other end of the cable. Sizes: packages.debian.org, trixie/arm64,
# 16.09.2026; "installed" is the recursive cost over what the image already has.
iputils-ping        # ping(8): tells "link down" from "no route" from "DNS".
                    # 243 KiB installed, no package pulled in behind it.
curl                # HTTP(S) client: fetch a file onto the device, check a
                    # release URL. 14 packages, 10.2 MiB -- libcurl4t64, and
                    # GnuTLS behind libldap2.
wget                # next to curl because it retries and resumes without a
                    # flag, and because half the recipes are written for it.
                    # 5 packages, 9.6 MiB; shares GnuTLS with curl, so the two
                    # together are 14.2 MiB, not 19.8.
netcat-openbsd      # nc(1): is the port open, and a pipe when there is no scp
                    # yet. 133 KiB installed, nothing pulled in behind it.

# --- Remote access -----------------------------------------------------------
openssh-server      # remote access. NO key in the image (doku/107 section 3) - the installer
                    # puts one in, otherwise you only get in over the serial console.

# --- File system, modules, block devices -------------------------------------
e2fsprogs           # mkfs.ext4/e2fsck/resize2fs; x-systemd.growfs in the fstab needs resize2fs
kmod                # modprobe/depmod for the 28 modules of the GOOD state
util-linux-extra    # agetty (NO longer in util-linux in trixie!) - without it no autologin on
                    # ttyS0; also fstrim(8) for the eMMC and the lsblk neighbours

# --- Sound -------------------------------------------------------------------
alsa-utils          # amixer/aplay: the audio path of h713-tv is checked with them (S25/S32)

# --- Runtime libraries of h713-tv --------------------------------------------
# `readelf -d h713-tv.aarch64-linux-gnu` names exactly three: libdrm.so.2,
# libasound.so.2, libc.so.6. libc comes from minbase, the other two from here.
libdrm2             # libdrm.so.2 - DRM/KMS plane
libasound2t64       # libasound.so.2 - ALSA control API (t64 rename in trixie)

# --- h713-pq ----------------------------------------------------------------
python3             # h713-pq computes gamma/presets at run time from /etc/hy310/tvconfig
                    # (doku/108 section 6). Standard library only, explicitly WITHOUT python3-dev.

# --- Wi-Fi (Marco, 12.09.: "gets the common tools") ---------------------------
# The driver has run on this kernel since 12.09., and h713-extract pulls the
# firmware out of the user's dump (analyse/boot/wlan-aic8800-messung-
# 20260912.txt). Those were the two reasons Wi-Fi was left out - gone.
# Operation: /etc/h713/wifi.env, evaluated by h713-wifi.service (overlay/).
wpasupplicant       # station (mode=sta): WPA2 login to someone else's network
hostapd             # access point (mode=ap, the default): SSID h713 / magcubic
dnsmasq-base        # DHCP for the AP clients. -base: only the program, NO
                    # dnsmasq.service, which would otherwise take port 53 on all
                    # interfaces - h713-wifi starts it itself on wlan0
iw                  # iw(8): scan, link state, regulatory domain - troubleshooting
                    # the radio without v4l2-ctl-style detours
rfkill              # rfkill unblock wifi before bring-up; without it a soft-blocked
                    # radio stays silent and nobody sees why
wireless-regdb      # regulatory.db for cfg80211. The aic8800 is self-managed and
                    # takes its table from the driver (default_ccode), but the
                    # global realm should still be right in case custregd ever falls

# --- Remote control: Bluetooth and infrared (FB-REMOTE, 27.09.2026) ----------
bluez               # bluetoothd, bluetoothctl, hciattach: HCI H4 on UART1 (h713-bluetooth.service);
                    # the hog plugin makes the stock BLE remote an evdev device through uhid,
                    # h713-remote-pair bonds it. The BT patch set IS in the dump (FB-BTFW).

# --- HDMI input diagnostics (TODO 5.12, Marco 08.10./12.10.) -------------------
v4l-utils           # v4l2-ctl: the HDMI receiver's signal, timings, controls and events through
                    # the plain V4L2 interface (/dev/video*) - missing at the device on 08.10.
                    # Only the command line tools and libv4l, no GUI (qv4l2 is its own package)

# --- U-Boot environment from Linux -------------------------------------------
libubootenv-tool    # fw_printenv/fw_setenv per /etc/fw_env.config (0x700000, 64 KiB).
                    # Without it there was the configuration file but no tool for it;
                    # h713_boot, h713_gate, h713_project are otherwise only reachable
                    # at the U-Boot prompt. Small (~100 KiB), no u-boot-tools needed.

# --- Clock (doku/107 section 8) ----------------------------------------------
systemd-timesyncd   # without a buffered RTC the system starts in 1970: apt fails at the
                    # signature check, logs are useless, every TLS connection breaks. ~1 MiB.
                    # Without a network it stays at the start value, then `date -u -s` as before.

# --- apt stays usable (doku/107 section 8) -----------------------------------
ca-certificates     # TLS roots for deb.debian.org and everything else over https
debian-archive-keyring  # /usr/share/keyrings/debian-archive-keyring.gpg - without it the
                    # configured source cannot be verified and `apt update` would be worthless.
                    # WARNING: `apt update` does not happen at BUILD time (~40 MiB of lists, out of
                    # date on the first day); build-rootfs.sh clears /var/lib/apt/lists.

# =============================================================================
# Deliberately NOT included - as a list, so that the decision can be read
# and does not quietly wander back in at the next build.

# build-essential, gcc, *-dev, meson, ninja, gdb, strace
#     doku/107 section 3: cross-built (userspace/h713-tv/Makefile, target install-cross).
#     The device compiles nothing.
# libgles2, libegl1, libgbm1, libgl1-mesa-dri
#     Since 22.09.2026 mesa does NOT come from Debian: libgbm1 alone pulls in mesa-libgallium
#     and libllvm19 (187 MiB installed). rootfs/mesa/build-mesa.sh cross-builds mesa
#     25.0.7 with only the Panfrost driver, EGL, GLES2 and GBM (15 MiB, no LLVM),
#     build-rootfs.sh puts it under /usr/local (--mesa). Reason: the keystone path
#     (working journal `keystone`).
# gstreamer1.0-*, mpv, ffmpeg
#     cstenger's video runtime (tools/rootfs/build.sh in his repository at 8860991, VIDEO_RUNTIME_PACKAGES).
#     Pulls in GTK3, x265, aom, libllvm - doku/107 section 1: the biggest single item of
#     today's netboot root. The projector moves HDMI input onto a DRM plane,
#     it decodes nothing. v4l-utils stood here with them until 12.10.2026; it is only
#     command line tools and libv4l, and is included above for v4l2-ctl (TODO 5.12).
# (bluez stood here until 27.09.2026 - "BT firmware not in the dump"; it is, FB-BTFW.)
# dnsmasq (the full package)
#     brings dnsmasq.service, which takes port 53 on all interfaces.
#     dnsmasq-base is enough; h713-wifi starts it itself and only on wlan0.
# busybox
#     a second toolbox without a job; util-linux and coreutils are there.
# zram-tools
#     doku/107 section 6/4.2: a unit of our own is smaller and does exactly the three settings
#     we want. See overlay/usr/local/sbin/hy310-zram-swap.
# firmware-*, all blob packages
#     doku/107 section 5: no proprietary blobs in the image. The installer puts firmware and PQ
#     data in from h713-extract.
