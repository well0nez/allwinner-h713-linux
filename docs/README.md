# Documentation

> **Read this first.** Everything in this project - the code, the firmware ports, the tools and these pages - was
> **generated by AI** in sessions directed by the maintainer, and it is **experimental**: no human has reviewed it line by
> line yet - the plan, now that a usable state is reached, is to check and validate every subsystem on its own -, there
> is no warranty, and you use it at your own risk and on your own device only. What does not work is written
> down in [known issues](known-issues.md); what has been measured, and when, in [STATUS.md](../STATUS.md).

Every page under `docs/`, so none is reachable only from inside another one. The project's entry point is
[../README.md](../README.md).

## Where a statement comes from

These pages are written to be complete and current. The evidence is the dated German working journal,
[`doku/`](../doku/README.md): [`doku/INDEX.md`](../doku/INDEX.md) §1 names, for every page here, the journal entries it
rests on. A page that says "not measured" means exactly that.
